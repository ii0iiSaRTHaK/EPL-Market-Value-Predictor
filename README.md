# EPL-Market-Value-Predictor

**[Open the live web app](https://epl-market-value-predictor.vercel.app/)**

Search Premier League players, explore historical season statistics, and request an experimental XGBoost market-value estimate. The interface uses the exact ThreeUI Sylva Living Green scene.
